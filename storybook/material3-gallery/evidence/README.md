# Native foundation gallery evidence

The selected comparison images in this directory are copied from the
Compose-first `M3-NAT-002` verification at
`9fe75263aab78c67dbe5fe49ef30b95ca872ee27`. `manifest.json` records the
source, native and zero-difference images, rendering environment, and hashes for
18 representative scenarios across all eight foundation dimensions. The live
gallery renders the current native package separately and labels this capture
revision, so later changes do not appear to have been compared already.

`OFL.txt`. See `../../THIRD_PARTY_NOTICES.md` and `../../LICENSE-APACHE-2.0`.

These are permanent documentation assets owned by the native package. The
disposable migration harness is not needed to build or display the gallery.

`ripple-compose-press.mp4` and `ripple-compose-state.mp4` retain the pinned
Compose source-value press and state-layer playback for native Ripple review.
They derive from AndroidX commit `a095da93f8e98dea8748ceed79ea8427aade245f`
and use the same licensed Roboto font. Their SHA-256 values are
`80a47f9a4c08fc19d6d846f60ea8f1a7b0d2f20e9403fdd1b2f255b06252f4ef`
